= 了解ASA r2 叢集中的ONTAP容量均衡
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
對於 ASA r2 系統，ONTAP 使用「均衡放置」功能，自動將新建立的儲存單元放置在最佳儲存可用度區，以達到最佳效能和均衡的儲存使用率。如果您執行的是 ONTAP 9.17.1 或更新版本，現有儲存單元所佔用的空間將使用「動態空間平衡」功能進行平衡。如果您執行的是 ONTAP 9.16.1，現有儲存單元所佔用的空間將使用「複本型工作負載重新平衡」功能進行平衡。

[cols="2"]
|===
| 功能 | 得到支持… 


| 均衡佈局 | ONTAP 9.16.1 及更高版本 


| 動態空間平衡 | ONTAP 9.17.1 及更高版本 


| 基於副本的工作負載重新平衡 | 僅限ONTAP 9.16.1 
|===
.均衡佈局
透過「均衡放置」，新建的儲存設備單元會自動放置在最佳儲存可用度區內，以實現最佳效能和均衡的儲存使用率。均衡放置功能在 ONTAP 9.16.1 及更新版本中預設為啟用。

.動態空間平衡
透過動態空間平衡，ONTAP 會主動監控叢集中的可用空間，並自動在儲存可用度區內移動儲存設備單元，以維持均衡的空間使用率。如果叢集容量使用率達到 80%，則會自動發出事件管理系統 （EMS） 警告；如果達到 90%，則會自動發出 EMS 警報。

升級到ONTAP 9.17.1 或更高版本後 14 天，動態空間平衡功能將預設為啟用。如果您需要修改預設的 14 天啟用期，請聯絡NetApp支援。啟用動態空間平衡後，無法從ONTAP 9.17.1 回溯。

動態空間平衡根據叢集中所有節點可用空間的總體平均值（全域平均值）以_正常模式_或_低空間模式_運行。

* *普通模式*
+
在正常模式下， ONTAP每三分鐘檢查一次，以確定是否需要動態空間平衡。當滿足以下條件時，動態空間平衡功能以正常模式運作：

+
** 全球平均空隙率為 10% 或更高。
** 叢集中至少有一個節點的可用空間比全局平均水準要多。
** 叢集中至少有一個節點的可用空間比全域平均少 20%。


* *低空間模式*
+
在低空間模式下， ONTAP每分鐘檢查一次，以確定是否需要動態空間平衡。當滿足以下條件時，動態空間均衡以低空間模式運作：

+
** 全球平均自由空間不足10%。
** 叢集中至少有一個節點的可用空間比全局平均水準要多。
** 叢集中至少有一個節點的可用空間少於全域平均水準。




.基於副本的工作負載重新平衡
使用 _基於複製的工作負載重新平衡_ 時，如果儲存可用度區內出現儲存使用率不平衡的情況， ONTAP 會自動將導致不平衡的儲存設備單元複製到具有更大可用空間的儲存可用度區。如果目的地儲存可用度區沒有足夠的可用空間， ONTAP 將不會執行任何平衡行動。基於複製的工作負載重新平衡僅適用於執行 ONTAP 9.16.1 的 ASA r2 系統，並且在這些系統上預設為啟用。在 ONTAP 9.17.1 及更新版本中，它已被動態空間平衡所取代。

如果您需要修改基於副本的工作負載重新平衡的預設設置，請聯絡NetApp支援。
