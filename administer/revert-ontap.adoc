= 在ASA r2 儲存系統上復原ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ASA r2 系統的ONTAP軟體復原遵循與其他ONTAP系統的復原相同的流程。

回復 ONTAP 叢集會造成服務中斷。您必須在回復期間將叢集離線。切勿在沒有技術支援協助的情況下回復正式作業叢集。您可以自行回復新建或測試叢集。如果新建或測試系統的回復失敗，或回復成功但您對正式作業環境中的叢集效能不滿意，則應聯絡技術支援尋求協助。

請參閱link:https://docs.netapp.com/us-en/ontap/revert/task_reverting_an_ontap_cluster.html["還原ONTAP集群"]以取得完整的回復程序。
