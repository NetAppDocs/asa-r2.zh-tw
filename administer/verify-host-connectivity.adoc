= 驗證 ASA R2 儲存系統上的主機連線能力
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果主機資料作業發生問題、您可以使用 ONTAP 系統管理員來驗證從主機到 ASA R2 儲存系統的連線是否為作用中。

.步驟
. 在 System Manager 中、選取 * 主機 * 。
+
System Manager 會在主機群組名稱旁顯示主機連線功能狀態：

+
** *OK*：表示所有啟動器都已連接至兩個節點。
** *Partially Connected*：表示某些啟動器未連接到兩個節點。
** * 無連線 * ：表示未連線任何啟動器。




.接下來呢？
在主機上進行更新以修正連線問題。ONTAP 將每 15 分鐘重新檢查連線狀態。
