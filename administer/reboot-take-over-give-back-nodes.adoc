= 重新啟動 ASA R2 儲存系統上的節點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可能需要重新開機節點以進行維護、疑難排解、軟體更新或其他管理操作。節點重新開機後，其 HA 合作夥伴會自動執行接管。重新開機後的節點恢復線上後，合作夥伴節點會自動執行歸還。

.步驟
. 在 System Manager 中、選取 * 叢集 > 總覽 * 。
. 選取image:icon_kabob.gif["三個垂直藍點"]您要重新開機的節點旁的、然後選取 * 重新開機 * 。
. 輸入您要重新啟動節點的原因、然後選取 * 重新開機 * 。
+
您輸入重新開機的原因會記錄在系統稽核記錄中。



.接下來呢？
節點重新開機期間，其 HA 合作夥伴會執行接管，以確保資料服務不會中斷。重新開機完成後，HA 合作夥伴會執行歸還。
