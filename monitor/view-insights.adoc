= 利用 ASA r2 系統 Insights 優化叢集安全性與效能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 ONTAP System Manager 中檢視 _Insights 、找出最佳實務做法和組態修改、以便在 ASA R2 系統上實作、以最佳化叢集安全性和效能。

例如，假設您已為叢集設定了網路時間協定 (NTP) 伺服器。但是，您並不清楚您設定的 NTP 伺服器數量少於實現最佳叢集時間管理所需的建議數量。為了協助您避免因叢集時間不準確而導致的問題，Insights 會通知您設定的 NTP 伺服器數量過少，並提供選項讓您深入瞭解問題、修正問題或關閉通知。

image:insights.png["系統管理員深入分析頁面的螢幕擷取畫面"]

.步驟
. 在 System Manager 中、選取 * Insights * 。
. 審查建議。


.下一步
執行任何必要的行動、以實作最佳實務做法、並最佳化叢集的安全性與效能。
