= ONTAP CLI 支援 ASA R2 儲存系統
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ASA r2 系統使用儲存可用度區而非彙總，因此某些 ONTAP CLI 命令和參數不受支援。如果您偏好使用 CLI 而非 System Manager，也可以使用 CLI 設定叢集。

由於這種簡化的儲存管理方法，  `storage aggregate` ASA r2 系統不支援 `lun` ，  `storage`和 `volume`命令和參數也受到限制。

除非列為不受支援，否則 link:https://docs.netapp.com/us-en/ontap-cli/["ONTAP 命令參照"] 中的所有其他命令均受 ASA r2 系統支援。

ASA r2 不支援以下命令和命令集：

.不支援的 <code> </code> 命令
[%collapsible]
====
* `lun copy`
* `lun geometry`
* `lun maxsize`
* `lun move`
* `lun move-in-volume`
+

NOTE: 這 `lun move-in-volume`命令被替換為 `lun rename`和 `vserver nvme namespace rename`命令。

* `lun transition`


====
.不支援的 <code> </code> 命令
[%collapsible]
====
* `storage failover show-takeover`
* `storage failover show-giveback`
* `storage disk assign`
* `storage disk partition`
* `storage disk reassign`


====
.不支援的 <code> tM1000e </code> 命令集
[%collapsible]
====
* `volume activity-tracking`
* `volume analytics`
* `volume conversion`
* `volume file`
* `volume flexcache`
* `volume flexgroup`
* `volume inode-upgrade`
* `volume object-store`
* `volume qtree`
* `volume quota`
* `volume reallocation`
* `volume rebalance`
* `volume recovery-queue`
* `volume schedule-style`


====
.不支援的 <code> </code> 命令和參數
[%collapsible]
====
* `volume autosize`
* `volume create`
* `volume delete`
* `volume expand`
* `volume modify`
+
當與下列參數搭配使用時， `volume modify` 命令無法使用：

+
** `-anti-ransomware-state`
** `-autosize`
** `-autosize-mode`
** `-autosize-shrik-threshold-percent`
** `-autosize-reset`
** `-group`
** `-is-cloud-write-enabled`
** `-is-space-enforcement-logical`
** `-max-autosize`
** `-min-autosize`
** `-offline`
** `-online`
** `-percent-snapshot-space`
** `-qos*`
** `-size`
** `-snapshot-policy`
** `-space-guarantee`
** `-space-mgmt-try-first`
** `-state`
** `-tiering-policy`
** `-tiering-minimum-cooling-days`
** `-user`
** `-unix-permisions`
** `-vserver-dr-protection`


* `volume make-vsroot`
* `volume mount`
* `volume move`
* `volume offline`
* `volume rehost`
* `volume rename`
* `volume restrict`
* `volume transition-prepare-to-downgrade`
* `volume unmount`


====
.不支援的 <code> 相關 </code> 命令
[%collapsible]
====
* `volume clone create`
* `volume clone split`


====
.不支援的 <code> SnapLock </code> 命令
[%collapsible]
====
* `volume snaplock modify`


====
.不支援的 <code> 快速 </code> 命令
[%collapsible]
====
* `volume snapshot`
* `volume snapshot autodelete modify`
* `volume snapshot policy modify`


====

== 使用 CLI 設定 ONTAP ASA R2 叢集

使用 link:../install-setup/initialize-ontap-cluster.html["System Manager 設定您的 ONTAP ASA r2 叢集"]。System Manager 提供快速簡單的引導式工作流程，讓您的叢集啟動並執行。不過，如果您習慣使用 ONTAP 命令，也可以選擇使用 ONTAP 命令列介面（CLI）來進行叢集設定。使用 CLI 設定叢集與 System Manager 相比，並未提供額外的選項或優勢。

在叢集設定過程中，ONTAP 會建立預設資料儲存設備虛擬機器 （VM）、建立初始儲存單元，並自動探索資料 LIF。您也可以選擇啟用網域名稱系統 （DNS） 以解析主機名稱、將叢集設定為使用網路時間協定 （NTP） 進行時間同步，以及啟用靜態資料加密。

.開始之前
收集下列資訊：

* 叢集管理IP位址
+
叢集管理 IP 位址是叢集管理員用來存取管理儲存 VM 及管理叢集的叢集管理介面唯一的 IPv4 位址。您可以向負責指派組織IP位址的管理員取得此IP位址。

* 網路子網路遮罩
+
在叢集設定期間、 ONTAP 會建議一組適合您組態的網路介面。如有必要、您可以調整建議。

* 網路閘道 IP 位址
* 合作夥伴節點 IP 位址
* DNS網域名稱
* DNS 名稱伺服器 IP 位址
* NTP 伺服器 IP 位址
* 資料子網路遮罩


.步驟
. 開啟 HA 配對的兩個節點。
. 顯示在本機網路上探索到的節點：
+
[source, cli]
----
system node show-discovered -is-in-cluster false
----
. 啟動叢集設定精靈：
+
[source, cli]
----
cluster setup
----
. 認可AutoSupport 此聲明。
. 輸入節點管理介面連接埠、 IP 位址、網路遮罩和預設閘道的值。
. 按 *Enter* 繼續使用命令列介面進行設定；然後輸入 *cre* 以建立新叢集。
. 接受系統預設值或輸入您自己的值。
. 第一個節點設定完成後，登入叢集。
. 驗證叢集是否為作用中、且第一個節點是否正常：
+
[source, cli]
----
system node show-discovered
----
. 將第二個節點新增至叢集：
+
[source, cli]
----
cluster add-node -cluster-ip <partner_node_ip_address>
----
. 您也可以在叢集之間同步處理系統時間
+
[cols="1h, 1"]
|===


| 不使用對稱驗證進行同步處理  a| 
[source, cli]
----
cluster time-service ntp server create -server <server_name>
----


| 與對稱驗證同步  a| 
[source, cli]
----
cluster time-service ntp server create -server <server_ip_address> -key-id <key_id>
----
|===
+
.. 確認叢集與 NTP 伺服器相關聯：
+
[source, cli]
----
Cluster time-service ntp show
----


. 或者、下載並執行link:https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor["ActiveIQ Config Advisor"]以確認您的組態。
