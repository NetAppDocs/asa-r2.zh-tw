= 為 ASA r2 系統上的 SnapMirror 作用中同步準備 AIX 主機
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
從 ONTAP 9.19.1 開始， SnapMirror active sync 支援在對稱式作用中/作用中組態的 AIX 主機上進行透明應用程式容錯移轉。SnapMirror active sync 可將應用程式透明地容錯移轉至次要複本，讓業務服務在發生完全站台故障時仍能繼續運作。

在為執行 ONTAP 9.19.1 或更高版本的 AIX 主機啟用 SnapMirror 主動式同步之前，必須將主機存取模式設定為本機。其他主機類型無需選擇存取模式。深入瞭解link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/interoperability-reference.html["SnapMirror 主動同步的互通性"^]。

.開始之前
您必須執行 ONTAP 9.19.1 或更新版本。如果您執行的是 ONTAP 9.18.1 或更早版本，則需要功能原則變更要求（FPVR），以取得 SnapMirror 主動同步的 AIX 主機支援。

.步驟
. 在 System Manager 中、選取 * Storage* 。
. 將滑鼠懸停在要準備啟用 SnapMirror 主動同步保護的 AIX 儲存單元的名稱上。
. 選擇 image:icon_kabob.gif["功能表選取圖示"]，然後選擇*編輯*。
. 在 *Host information* 下，針對 *Access mode* 選取 *local*，然後選取 *Edit*。


.接下來呢？
AIX 主機的儲存單元已準備好進行 SnapMirror 主動同步保護。
