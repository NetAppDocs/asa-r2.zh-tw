= 提交及檢視 ASA R2 儲存系統的支援案例
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您遇到需要協助的問題，請使用 ONTAP System Manager 向技術支援提交案例，或檢視已關閉或正在處理的案例。

您必須是link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["已向 Active IQ 註冊"^]才能查看 ASA r2 系統的支援案例。

.步驟
. 若要提交支援案例，請在 System Manager 中選擇「叢集 > 支援」；然後選擇「前往 NetApp 支援」。
. 若要檢視先前提交的案例，請在 System Manager 中選擇「叢集 > 支援」；然後選擇「檢視我的案例」。
