= 修改ASA r2 儲存系統上的 ARP/AI 快照保留期
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果具備人工智慧的自主勒索軟體防護 (ARP/AI) 偵測到 ASA r2 系統上一個或多個儲存設備單元有異常活動，則會自動建立 ARP 快照以保護資料。根據您的儲存容量和業務需求，您可能需要增加或減少預設的 ARP 快照保留期間。例如，您可以增加關鍵業務應用程式的保留期間，以支援更長的資料恢復窗口，或減少非關鍵應用程式的保留期間，以節省儲存空間。

ARP 快照的預設保留期取決於您針對異常活動所採取的措施。

[cols="2,2"]
|===
| 如果您採取此行動... | ARP 快照預設保留... 


| 標記為誤報 | 12小時 


| 標記為潛在勒索軟體攻擊 | 7天 


| 不立即採取行動 | 10天 
|===
您可以使用 ONTAP 命令列介面 （CLI） 修改預設保留期間。請參閱 https://docs.netapp.com/us-en/ontap/anti-ransomware/modify-automatic-snapshot-options-task.html["修改ONTAP自動快照的選項"]以取得變更預設保留期間的步驟。
