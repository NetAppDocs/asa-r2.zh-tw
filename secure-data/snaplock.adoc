= 了解適用於 ASA r2 儲存設備系統的 SnapLock 資料保護
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP SnapLock 是一款高效能的法規遵循解決方案，適用於使用 WORM 儲存設備以未修改形式保留檔案，以達到法規監管和治理目的之組織。您可以在 SnapLock Compliance 或 Enterprise 模式下執行 SnapLock，這兩種模式提供不同層級的 WORM 資料保護。SAN 環境中的主要叢集不支援 SnapLock Compliance 和 Enterprise 模式，但您可以在次要系統上啟用 SnapLock for SnapVault，以保護次要快照免受意外或惡意刪除。

SnapLock 法規遵循時鐘必須初始化為 link:../data-protection/snapshot-replication.html["使用 SnapLock for SnapVault 保護次要系統上的快照"]。

從 ONTAP 9.20.1 開始，您可以透過現有的 FC 架構設定後端 SnapLock for SnapVault 複寫。若要這麼做，您的 ONTAP 系統後端必須設定為 FC 複寫，且 FC 架構和叢集間 IP 網路都必須正常運作。複寫資料可以透過 FC 架構傳輸，但叢集通訊和複寫管理功能需要叢集間 IP 網路。

了解如何link:https://docs.netapp.com/us-en/ontap/data-protection/configure-backend-fc-replication.html["設定 ONTAP 系統後端以進行 FC 複寫"^]。

== 初始化 SnapLock Compliance 時鐘

如果要使用 SnapLock for SnapVault 來保護二線系統上的目的地快照，則必須先在本機叢集和目的地叢集上初始化 SnapLock Compliance Clock。

.步驟
. 選擇*叢集>總覽*。
. 在 * 節點 * 區段中、選取 * 初始化 SnapLock Compliance 時鐘 * 。
. 選擇 * 初始化 * 。
. 確認合規時鐘已初始化。
+
.. 選擇*叢集>總覽*。
.. 在 * 節點 * 區段中image:icon_show_hide.png["白色背景上的三個藍色欄"]、選取；然後選取 * SnapLock Compliance 時鐘 * 。




.接下來呢？
在本機和目的地叢集上初始化 SnapLock Compliance Clock 後，即可準備好 link:../data-protection/snapshot-replication.html["建立與 SnapLock for SnapVault 的複寫關係"]。
